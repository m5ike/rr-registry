Hostujte vlastní balíčky, zrcadlete npmjs.org s cache, směrujte požadavky na další registry a spravujte vše přes web, CLI, bash GUI nebo REST API.

Začínáme

1. Nastavte registr

npm config set registry {{BASE}}/
# jen pro jeden projekt (.npmrc):
registry={{BASE}}/
# pouze vlastní scope:
@firma:registry={{BASE}}/

2. Přihlaste se a publikujte

npm login --registry {{BASE}}/ --auth-type=legacy
# nebo token do .npmrc:
{{HOST}}/:_authToken=<token>
npm publish

3. Instalujte

npm install lodash      # z cache / npmjs.org
npm install @firma/lib  # z lokálního repozitáře
yarn config set npmRegistryServer {{BASE}}/
pnpm config set registry {{BASE}}/

Zrcadla GitHubu

Pull zrcadlo udržuje lokální kopii repozitáře z GitHubu (plánovaně, při přístupu nebo webhookem), push zrcadlo po každém push odešle změny na GitHub. Hromadný import celé organizace jedním příkazem.

rr git github git moje-org --token ghp_…

Směrování a cache

Pravidla

Routing plugin přesměruje požadavek na jiný registr podle masky URL (prefix, glob, regex), části URL, klíče (/~klic/, hlavička X-RR-Key, ?rr_key=), hlavičky požadavku, nebo pokud balíček není nalezen lokálně.

Cache

Vzdálená metadata i tarbally se ukládají do cache na disku. Další požadavky se servírují přímo z ní až do vypršení platnosti; při výpadku upstreamu se použije i expirovaná kopie.

Příklad

rr route add name=corp when=always \
  matchType=prefix pattern=/@corp/ \
  target=https://npm.corp.example cacheTtl=600
npm config set registry {{BASE}}/~corp/
