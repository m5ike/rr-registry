Hostujte npm balíčky, Docker image, git repozitáře i soubory na vlastním serveru. Co nemáte, se stáhne a uloží do cache. Co publikujete, se může samo zreplikovat dál.

Začínáme

1

Nastavte registr

npm config set registry {{BASE}}/
# jen pro jeden projekt (.npmrc):
registry={{BASE}}/
# jen vlastní scope:
@firma:registry={{BASE}}/
2

Přihlaste se a publikujte

npm login --registry {{BASE}}/ --auth-type=legacy
# nebo token do .npmrc:
{{HOST}}/:_authToken=<token>
npm publish
3

Instalujte cokoli

npm install lodash      # z cache / upstreamu
npm install @firma/lib  # z lokálního repozitáře
yarn config set npmRegistryServer {{BASE}}/
pnpm config set registry {{BASE}}/

RepozitářTypAdresaPopis

Čtyři kotviště, jedna adresa

npm a spol.

Publikace, dist-tagy, vyhledávání a audit. Funguje s yarn, pnpm, bun i deno.

npm publish --registry {{BASE}}/

Docker image

Docker Registry API v2: push, pull, multi-platform indexy a úklid nepoužitých vrstev.

docker push {{DOCKERHOST}}/tym/app:1.0

Git

Clone a push přes HTTP, chráněné větve, zrcadla z GitHubu a automatický push zpět.

git push {{BASE}}/git/tym/api.git

Soubory

Buildy, archivy a dokumentace s retencí, kvótami a neměnnými verzemi.

curl -T app.zip {{BASE}}/r/files/

Klienti maintainer m5ike

curl -fsSL {{BASE}}/install.sh | bash

Všechny nástroje volají správcovské API přes klientskou knihovnu, která se generuje při sestavení serveru ze specifikace API. Instalátor je uloží do ~/.local/bin; jen vybraný klient: | bash -s -- rr_bash-cli.
